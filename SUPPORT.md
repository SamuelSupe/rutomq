# Support

Choose the channel that matches the request:

| Request | Channel |
| --- | --- |
| Usage, architecture, or evaluation question | [GitHub Discussions](https://github.com/SamuelSupe/rutomq/discussions) |
| Reproducible defect | [Bug report](https://github.com/SamuelSupe/rutomq/issues/new?template=bug_report.yml) |
| Compatibility or feature proposal | [Feature request](https://github.com/SamuelSupe/rutomq/issues/new?template=feature_request.yml) |
| Security vulnerability | [Private vulnerability report](https://github.com/SamuelSupe/rutomq/security/advisories/new) |

Before requesting support, include the rutomq version, Kafka client and version,
deployment shape, relevant configuration with secrets removed, and a minimal
reproduction. The `v0.1.x` line is a public preview and does not include a
commercial support or response-time commitment.
